# 장전 테마 예측 방법 (07:00 시작, 07:30 전 게시)

결과는 `python3 scripts/publish_section.py pre /tmp/pre.json YYYY-MM-DD` 로 공개 달력에 올린다.
예측 테마 이름은 달력에서 쓰는 이름 그대로 쓴다.

## 0. 기본 점수부터 뽑는다
`python3 scripts/pre_score.py YYYY-MM-DD` → 테마별 점수·근거·유사테마(data/ref/pre_score.json).
- 기본: 최근 20거래일 주도 비율 (이것만으로 지난 기록 적중 32%, 하루 1개 이상 82% — 넘어야 할 기준선)
- 미국 신호: 지난 기록에서 미국 짝과 연관이 확인된 테마에만 더한다 (data/ref/us_link.json, 매일 자동 갱신)
  · 연관이 확인된 테마 예: 반도체 소부장(미국 +2%↑일 때 주도 67% / -2%↓일 때 20%), 광통신(33% / 0%)
  · 제약·바이오, 로봇, 방산·우주항공은 미국 짝과 연관이 약함 → 국내 뉴스·사건으로 판단
- 점수 + 미국 신호 검증 결과(지난 44거래일): 적중 34%, 하루 1개 이상 84% (기준선보다 소폭 높음)
- 그 위에 아래 2~5단계(뉴스·사건·원자재·달력 흐름)로 더하거나 빼서 최종 3개를 고른다.

## 1. 미국 지수·시황 (한 줄 요약용)
나스닥, S&P500, 필라델피아 반도체지수, WTI·브렌트, 원/달러, 미 10년물 금리.

## 2. 달력 테마별 미국 짝 종목을 하나씩 확인 (지수만 보고 끝내지 않는다)
| 달력 테마 | 미국 짝 (전날 등락·뉴스 확인) |
|---|---|
| 반도체 소부장 | 어플라이드머티리얼즈, 램리서치, KLA, ASML |
| 반도체 | 마이크론, 엔비디아, SK하이닉스 ADR, 시놉시스·케이던스(설계) |
| 광통신 | 코히런트, 루멘텀, 코닝, 시에나, AAOI, 광학 ETF(LYTE) |
| 전자부품 | 기판·MLCC 관련(TTM, 무라타 ADR), 애플 부품 뉴스 |
| 2차전지 | 테슬라, 앨버말, SQM, 리튬 가격 |
| 원전·에너지 | 콘스텔레이션, 비스트라, 오클로, 뉴스케일, 우라늄(카메코) |
| 전력기기·전선 | GE버노바, 이튼, 버티브 |
| 방산·우주항공 | 로켓랩, AST스페이스모바일, 록히드, 스페이스X 발사·도킹 일정 |
| 로봇 | 테슬라 옵티머스 뉴스, 엔비디아 로봇 발표, 휴머노이드 기업 뉴스 |
| 제약·바이오 | XBI(바이오 ETF), 일라이릴리, 노보, 대형 기술수출 뉴스 |
| 정유·화학 | 유가, 엑슨·발레로 |
| 조선·해운 | 운임지수, LNG선 발주 뉴스 |
| 디지털자산 | 비트코인, 코인베이스, 스테이블코인 법안 |

## 3. 밤사이 사건 뉴스 검색 (지표에 안 나오는 재료)
- 우주 발사·도킹, 대형 수주, 정책 발표(미국·한국), 빅테크 투자 발표, FDA 승인
- 장 마감 후 국내 공시·정부 발표 (예: 10/1 장 마감 후 美 원전 8기 발표)

## 4. 원자재·지표가 번지는 방향까지 본다
- 유가 급등 → 정유·화학, 2차전지·전기차(대체 수요), 해운·조선
- 금리 급등 → 코스닥 소형 성장주 부담, 은행·보험
- 원화 약세 → 수출주, 원화 강세 → 내수주

## 5. 달력 흐름 반영
- 최근 20거래일에 반복 등장한 테마·종목, 3개월 주도 횟수, 마지막 주도 후 경과일(순환 주기)
- 전날 이미 크게 오른 테마는 미국이 좋아도 차익 매물 가능성을 함께 적는다

## 6. 유사테마
pre_score.json 의 similar(최근 60거래일 함께 움직인 테마)를 참고한다. 사이트는 예측 테마 옆에 유사테마를 자동으로 보여 준다.
대표 묶음: 광통신·전력기기·전선·통신장비(AI 인프라), 호남 반도체 클러스터·건설, AI 소프트웨어·보안.

## 7. 고르는 기준
- 미국 짝 종목이 크게 움직였고(±3% 이상) 달력에서도 최근 자주 도는 테마를 우선
- 예측 5개(가능성 높은 순) + 조심할 테마 1개. 근거(why)에는 미국 수치, note에는 달력 기록을 적는다
