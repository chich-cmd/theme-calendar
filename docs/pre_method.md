# 장전 테마 예측 방법 (07:00 시작, 07:30 전 게시)

## ★ 원칙: 데이터대로만 (2026-10-06 사용자 지시)
- 최종 5개와 순서 = `pre_score.py` 점수 순 상위 5개 그대로. 판단으로 순서를 바꾸거나 빼지 않는다
- 뉴스·기사·일정은 아래 고정 가중치로 data/ref/events.json 에 넣어 **점수로만** 반영한다 (점수 += 0.3 × weight)
  | 종류 | weight |
  |---|---|
  | 당일·전날 밤 대형 실적 (삼성전자, 마이크론 등) | 1.0 |
  | 정부 정책·대출·규제 발표 (국내·미국) | 0.6 |
  | 대형 계약·수주 (미국 짝 기업 포함) | 0.6 |
  | 국내외 대형 사건·사고 (해킹, 재난, 사고, 분쟁 — 수혜 테마에) | 0.6 |
  | 테마주 신규상장 당일 | 0.5 |
  | 장전 기사 2곳 이상 같은 업종(반도체 제외) | 0.3 |
  | 실적 발표 전날 기대 | 0.5 |
- 순서: 06:30 미국 데이터 갱신 확인 → 뉴스·기사·일정 수집 → events.json 기록 → `python3 scripts/pre_score.py 날짜 --emit /tmp/pre.json` → 그대로 게시
- 조심 테마도 데이터로: 미국 짝 종목 평균 −2% 이하 테마(없으면 비움)
- 관련주 = 테마별 최근 3개월 추세 상위 5종목(emit 이 자동으로 note 에 넣음)

결과는 `python3 scripts/publish_section.py pre /tmp/pre.json YYYY-MM-DD` 로 공개 달력에 올린다.
예측 테마 이름은 달력에서 쓰는 이름 그대로 쓴다.

- 예측 5개(가능성 높은 순) + 조심할 테마 1개. 근거(why)에는 미국 수치·일정, note에는 달력 기록을 적는다
- 각 예측에 src 를 꼭 적는다 (채점용, 사이트에는 안 보임):

  src 값: base(달력 순환) · us(미국 짝) · event(예정 일정) · article(장전 기사) · nxt(넥장 흐름) · news(밤사이 사건)

## 8. 대장주가 아니라 테마 전체로 판단
- 3개월 기록에서 대장주(거래대금 1위)가 다음번에도 대장인 경우는 8%, 다시 급등 목록에 드는 경우도 14%뿐
- 그래서 테마 판단은 "몇 종목이 같이 올랐나 + 거래대금 비중"으로 하고, 종목 하나의 움직임을 테마 신호로 쓰지 않는다
- 관련주는 pre_score.json 의 basket = 최근 3개월(60거래일) 달력에서 그 테마로 2번 이상 급등한 종목 중,
  네이버 분류상 그 테마가 주 테마인 종목 우선 → 최근일수록 무게를 둔 등장 횟수 순 → 같으면 3개월 추세 순 5종목.
  보안·우주항공·방산은 핵심 네이버 테마+사업 설명 키워드에 맞는 종목만 쓴다(pre_score.py CORE). 예: 보안 = 보안주(정보) 중 정보보안·인증·관제 기업, CCTV·지문·보안인쇄 제외
  (10/6 개정: 추세만 보면 스피어·센서뷰 같은 핵심 우주주가 빠졌다. 방산·우주항공은 10/6부터 '방산'과 '우주항공'으로 분리)
  예측에 넣은 테마가 상위 10개 밖이면 baskets[테마] 를 쓴다. note 에 "관련주 A·B·C·D·E" 로 5개만 적는다
  그날 재료와 직접 연결된 종목(예: 스페이스X 공급사)이 있으면 why 에 따로 적는다
- leader_keep(대장 유지율)이 높은 테마(광통신 42%, 호남 반도체 클러스터 40%, 철강 27%, 원전 25%)만 대장주를 참고할 수 있다
